Capstone Deep Dive

Online Quiz Examinations System

📌 Project Scope & Goal

The Online Quiz Examinations system was built to provide an automated, transparent, and user-friendly testing environment. Developed for educational evaluations, it minimizes manual grading delays and delivers dynamic test sessions.

⚙️ Key Architectural Features

  • Automated Question Shuffling: Dynamically loads test questions to ensure fair testing.
  • Session Countdown: Precise real-time timer preventing late submissions.
  • Instant Scorecard Generator: Computes percentage, grade, and question-by-question review immediately upon test finish.
  • Java OOP Design: Structured classes representing Questions, Exam Sessions, User Candidates, and Assessment Evaluators.
